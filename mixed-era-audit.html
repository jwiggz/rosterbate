Tier Integrity Bands

Review

Tier Integrity: pass if bands show believable cross-era representation, tune if one era is over-centred in a band, and fail if a single era appears to capture a tier outright.

Star Fairness Check

Review

Star Fairness: pass if the top-star conversation feels believable overall, tune if one or two comparisons are arguable, and fail if multiple headline stars are clearly misplaced by tier.

  • Does the top tier still read like the league's obvious alpha group?
  • Do the borderline legends land in the right neighborhood?

Raw vs Normalized Sanity Check

Review

Raw vs Normalized: pass if the shifts feel directional rather than absurd, tune if there are a handful of suspicious corrections, and fail if normalized order repeatedly contradicts production context in impossible ways.

  • Does normalization improve the board without flipping obvious production reality?
  • Are the biggest corrections explainable to a human reviewer?

Draft-Feel Check

Review

Draft-Feel: pass if the board feels exciting and credible, tune if it is fun but has a few obvious "why is he here?" names, and fail if a human reviewer would hesitate to draft from it.

  • Would you be comfortable drafting from this board without a disclaimer?
  • Do the surprise names feel fun, or do they break the board's trust?
